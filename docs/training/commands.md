# Commands

Danh sách dưới đây là khung tham khảo để bạn thay bằng command thực tế của server.

| Nhóm | Ví dụ | Mục đích |
| --- | --- | --- |
| Radio | `/r` | Liên lạc nội bộ |
| Global | `/g` | Kênh liên lạc theo hệ thống server |
| Backup | `/backup` | Gọi hỗ trợ |
| RP | `/me`, `/do` | Thể hiện hành động / trạng thái RP |
| Báo cáo | Command report của server | Gửi tình huống |

> Hãy cập nhật bảng này theo đúng gamemode thực tế để tránh sai lệch command.
